# Tetris em C

Projeto de estudo de Tetris feito em C usando Raylib.

## Requisitos

- GCC
- make
- Raylib instalada no sistema

## Como rodar

Na raiz do projeto, execute:

```bash
make run
```

Esse comando:

1. cria a pasta build automaticamente
2. compila os arquivos C
3. executa o jogo

## Comandos úteis

Compilar sem executar:

```bash
make compile
```

Executar o binário já compilado:

```bash
./build/main
```
